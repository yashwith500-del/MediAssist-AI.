# MediAssist AI

MediAssist AI is an AI-powered healthcare assistance prototype designed to collect basic health measurements and provide structured health-related information using Google's Gemini AI.

## Features

- AI-powered medical information assistance using Gemini.
- Structured responses to health-related questions.
- Heart rate monitoring using the MAX30102 sensor (hardware integration pending).
- Web-based dashboard using HTML, CSS, and JavaScript.
- Python Flask backend.
- Planned ESP32 integration for sensor data collection.

## Technologies Used

- Python
- Flask
- Google Gemini API
- HTML, CSS, JavaScript
- ESP32 and MAX30102 (planned hardware integration)

## Project Status

Software prototype developed. Physical sensor integration is still in progress.

## Setup

1. Clone the repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Configure your Gemini API key in a local `.env` file.
4. Start the Flask application.

## Disclaimer

MediAssist AI is an educational prototype, not a certified medical device. Its responses are informational and must not replace professional medical advice or diagnosis.
